# 자산 연동 목데이터

자산 연동은 커플 합산 연동이 아니라 회원별 개인 연동이다. 각 회원이 자신의 JWT로
`POST /v1/members/me/assets`를 호출하면 자신의 `member_id`에만 금융 요약이 저장된다.
궁합 계산과 공동 추천 단계에서 두 회원의 개인 요약을 조회해 합산한다.

현재는 외부 목 서버 대신 `SimpleMyDataProvider`가 예비부부용 개인 시나리오 두 개를 반환한다.
회원가입 직후에는 아직 커플 관계가 없어 상대방 역할을 조회할 수 없으므로, 임시로 홀수 회원 ID는
개인 A, 짝수 회원 ID는 개인 B를 사용한다. 목 서버를 붙일 때는 `MyDataProvider`의 HTTP 구현으로
교체하고 컨트롤러·서비스·매퍼는 유지한다.

## 개인 A — 부채 없음

| 원천 항목 | 금액 |
| --- | ---: |
| 입출금 | 12,630,000원 |
| 예적금 | 50,520,000원 |
| 일반 투자 | 9,050,000원 |
| 연금저축 | 6,000,000원 |
| ISA | 6,000,000원 |
| 총 금융자산 | 84,200,000원 |
| 총 부채·향후 12개월 상환액 | 0원 |

- 연금저축 연 납입액 480만원
- ISA 연 입금액 600만원
- IRP 미보유

## 개인 B — 전세자금대출 보유

| 원천 항목 | 금액 |
| --- | ---: |
| 입출금 | 8,400,000원 |
| 예적금 | 30,600,000원 |
| 일반 투자 | 20,000,000원 |
| IRP | 4,000,000원 |
| 총 금융자산 | 63,000,000원 |
| 전세자금대출 | 35,000,000원 |
| 향후 12개월 상환액 | 3,600,000원 |
| 대출금리 | 4.15% |

- IRP 연 납입액 300만원
- 연금저축·ISA 미보유
- 고금리 대출 아님

두 사람의 합산 금융자산은 1억 4,720만원, 합산 부채는 3,500만원이다. 한 사람은 부채가 없고
다른 사람은 감당 가능한 전세자금대출을 보유해, 예비부부에게 현실적인 자산 차이와 부채 부담이
궁합 점수에 반영된다.

입출금 합계가 예금 추천 기준 600만원을 넘고 고금리 대출은 아니므로 예금·대출 추천을 막지 않는다.
연금·IRP·ISA는 두 사람이 서로 다르게 보유해 개인 절세 추천도 각자 다르게 생성될 수 있다.

적금·투자·대출 추천의 나머지 조건은 마이데이터가 아니라 개인·공동 설문에서 결정된다.
적금은 커플 월 가용금액이 0보다 커야 하고, 투자는 한 달 내 대출 계획이 없어야 하며, 대출은
공동 설문에 대출 목적이 있어야 한다.
